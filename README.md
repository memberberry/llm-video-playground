# My FastAPI Service

This is a FastAPI service with a structured project layout.

## To Run

1. Setup venv:
   ```bash
   python -m venv venv
   ```
2. activate venv:
   ```bash
   source venv/bin/activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the development server:
   ```bash
   uvicorn api.main:app --reload
